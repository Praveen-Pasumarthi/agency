# AI Prompts Library

Use these prompts with AI assistants (ChatGPT, Claude, etc.) to speed up your workflow.

---

## Client Research

### Research a Business
```
Research [Business Name] in [City]. Find:
- Business type and services
- Google rating and reviews
- Current website (if any) and its quality
- Instagram handle and follower count
- Pain points that a website could solve
- Competitor names

Format as a structured report.
```

### Generate Outreach Message
```
Write a personalized WhatsApp message for a [business type] called [Name] in [City].

They have:
- No website / outdated website
- Good Google rating ([X] stars)
- [Specific observation about their business]

The message should:
- Be friendly and professional
- Mention something specific about their business
- NOT be salesy
- Offer to show a free demo
- Be under 100 words
```

## Business & Sales

### Write Proposal
```
Write a professional website proposal for a [business type] called [Name].

Business details:
- Location: [City]
- Current online presence: [Description]
- Pain points: [List]
- Budget range: ₹[X] - ₹[Y]

The proposal should include:
1. Executive summary
2. Understanding of their business
3. Proposed solution
4. Features list
5. Timeline
6. Pricing breakdown
7. Why choose us
8. Next steps

Tone: Professional but warm. Focus on outcomes, not features.
```

### Create Quote
```
Create a detailed quote for a website project:

Client: [Name]
Business: [Type]
Requirements: [List features]

Pricing:
- Base website: ₹[X]
- Additional features: ₹[X each]

Include:
- Itemized list
- GST (18%)
- Payment terms (50% advance)
- Validity (30 days)
- What's included/excluded
```

### Handle Objections
```
A potential client said: "[objection]"

Help me respond professionally with:
1. Acknowledge their concern
2. Provide a solution or alternative
3. Reinforce the value
4. Move the conversation forward

Keep it under 50 words. Don't be pushy.
```

## Content Creation

### Write Website Copy
```
Write homepage copy for a [business type] called [Name].

Target audience: [Description]
Key selling points: [List]
Tone: [Professional/Friendly/Luxury/Modern]

Include:
1. Hero headline (under 10 words)
2. Hero subheadline (under 30 words)
3. Feature section (3 features with icons)
4. Call to action
5. Social proof section

Focus on outcomes, not features.
```

### SEO Meta Tags
```
Generate SEO meta tags for a [business type] website in [City]:

Business: [Name]
Services: [List]
Target keywords: [List]

Provide:
1. Title tag (under 60 characters)
2. Meta description (under 160 characters)
3. H1 heading
4. 5 H2 headings for sections
5. Alt text for 3 images
```

### Google Business Description
```
Write a Google Business Profile description for a [business type] called [Name] in [City].

Max 750 characters. Include:
- What they do
- Key services
- Location
- What makes them unique
- Call to action
```
