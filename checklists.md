# Project Delivery Checklists

## Pre-Project Checklist

### Before Starting
- [ ] Client has approved proposal
- [ ] 50% advance received
- [ ] Business name confirmed
- [ ] Domain name confirmed (or help them buy one)
- [ ] Hosting decided (recommend Netlify/Vercel — free)
- [ ] Brand colors identified
- [ ] Logo file received (or create simple one)
- [ ] Content provided (text, images, menu)
- [ ] Contact details (phone, email, address)
- [ ] Social media links
- [ ] WhatsApp number confirmed

---

## Asset Checklist

### From Client
- [ ] Business name and tagline
- [ ] Logo (high-res PNG/SVG)
- [ ] Brand colors (or we choose)
- [ ] Professional photos (or stock images)
- [ ] Menu / services list with prices
- [ ] About us text
- [ ] Contact info (phone, email, address)
- [ ] Social media links
- [ ] Google Maps location
- [ ] WhatsApp number
- [ ] Any specific requirements

### We Create
- [ ] Color palette
- [ ] Typography selection
- [ ] Layout mockup
- [ ] Placeholder content (if client hasn't provided)

## Pre-Launch Checklist

### Testing
- [ ] Test on iPhone (Safari)
- [ ] Test on Android (Chrome)
- [ ] Test on iPad
- [ ] Test on desktop (Chrome)
- [ ] Test on desktop (Firefox)
- [ ] Test contact form submission
- [ ] Test WhatsApp button
- [ ] Test all links
- [ ] Test loading speed (PageSpeed Insights)
- [ ] Check for typos
- [ ] Check all images loading
- [ ] Check dark mode (if applicable)

### SEO
- [ ] Title tag set
- [ ] Meta description set
- [ ] H1 heading set
- [ ] Image alt tags added
- [ ] Sitemap created
- [ ] robots.txt created
- [ ] Google Analytics added (optional)

---

## Launch Checklist

### Deployment
- [ ] Domain connected
- [ ] SSL certificate active
- [ ] Website live and accessible
- [ ] All pages loading correctly
- [ ] Contact form receiving submissions
- [ ] WhatsApp button functioning
- [ ] Google Maps displaying correctly

### Client Handoff
- [ ] Domain login credentials shared
- [ ] Hosting dashboard access shared
- [ ] Website walkthrough video recorded
- [ ] How to edit content documented
- [ ] Support period explained (1 month)
- [ ] Maintenance plan offered

---

## Post-Launch Checklist

### Week 1
- [ ] Check website performance
- [ ] Monitor form submissions
- [ ] Fix any issues reported
- [ ] Client feedback collected

### Month 1
- [ ] Request testimonial
- [ ] Ask for referrals
- [ ] Offer maintenance plan
- [ ] Check for upsell opportunities

---

## Invoice Checklist

- [ ] Invoice number assigned
- [ ] Client name and business name
- [ ] Items itemized
- [ ] GST (18%) added
- [ ] Payment terms stated
- [ ] UPI/Bank details included
- [ ] Thank you note added
